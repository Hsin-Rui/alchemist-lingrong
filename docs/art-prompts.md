# 美術素材提示詞（給 ChatGPT 生圖用）

> 對應設計文件：`docs/game-design.md`｜共 17 張圖（11 張角色、5 張背景、3 張道具總表），另有 3 張選做背景

---

## 使用方法

1. 開一個**新的** ChatGPT 對話。
2. 貼上〈步驟 0：專案脈絡〉，讓它先了解我們在做什麼（這一步先不生圖）。
3. 照順序生圖。**第一張零溶最重要**，反覆修改到滿意為止，這張就是「標準圖」。
4. 之後每一張都**重新上傳標準圖**，提示詞已經寫好「參考附圖畫風」。對話越長，AI 越容易跑掉畫風，所以每次都上傳最保險。
5. 下載後照每段寫的**檔名**存進 `assets/` 對應的資料夾。
6. 角色和道具如果沒有變成透明背景，用 Finder 對圖片按右鍵，選「快速動作 → 移除背景」。

> 圖片裡**不要有任何文字**。AI 寫中文常常會寫錯，遊戲標題和字由程式另外加上去。

## 步驟 0：專案脈絡（先貼這段）

```
我正在開發一款網頁小遊戲，接下來會請你幫我生成一系列遊戲美術素材。請先閱讀以下說明，記住這些設定，之後每次生圖都要遵守。這則訊息先不用生圖，回覆「了解」即可。

【遊戲簡介】
遊戲名稱：《煉金術士零溶——逆襲a零溶》
這是一款同人搞笑（kuso）小遊戲，靈感來自清宮劇的後宮鬥爭，玩法參考日本的「鍊金術士」系列：主角在自己的宮殿裡經營一間煉金工房，接其他妃嬪的訂單，做出安神香、糕點、養顏膏等東西，再偷偷「加料」整她們。整體調性是誇張、惡趣味、不正經的喜劇，不是嚴肅宮鬥劇。

【畫風規格（所有圖片都要一致）】
- Q版大頭比例（約 2.5～3 頭身），可愛、圓潤
- 清朝宮廷風的服裝與場景（旗頭、宮裝、宮殿建築）
- 2D 插畫，乾淨的線條，柔和的賽璐璐上色，色彩明亮飽和
- 像手機遊戲或日系獨立遊戲的角色立繪
- 表情要誇張、有喜劇感

【重要限制】
- 所有角色都是原創設計，不要模仿任何真實演員或真人的長相
- 圖片裡不要出現任何文字、字母、浮水印或簽名
- 不要有血腥、恐怖或寫實的暴力畫面，「壞事」用搞笑誇張的方式表現
- 角色立繪：全身、正面或微側、單一角色、透明背景（做不到就用純白背景）
- 背景圖：直式構圖、不要有人物
- 這些素材會用在手機直式畫面的網頁遊戲中

【角色一覽】
1. 零溶（主角）：安嬪，外表柔弱乖巧的小家碧玉，其實是腹黑的煉金術士
2. 包捐：零溶的貼身宮女，忠心又精明的跑腿小幫手
3. 滑妃：囂張華麗的寵妃，紅金色系
4. 審沒裝：端莊穩重的妃嬪，橘黃色系，菊花意象
5. 真環：溫柔清秀但眼神精明的妃嬪，粉白色系，梅花意象
6. 黃上：皇帝，只在搞笑結果畫面中客串
7. 太醫溫十粗：抓到主角加料的太醫，一本正經的書呆子
8. 黃后：後宮之主，表面慈祥、城府極深

了解後請回覆「了解」，我會一張一張請你畫。
```

## 步驟 2：背景

存放資料夾：`assets/backgrounds/`
規格：直式（2:3，例如 1024×1536），**不要有人物**，畫面下方約 1/3 的細節少一點（會放角色和按鈕）

```
（附上零溶標準圖，作為畫風參考）
請用跟附圖相同的畫風，畫一張遊戲背景「炎洗宮・零溶的煉金工房」：
```

## 常用的修改說法

| 問題 | 跟 ChatGPT 說 |
|---|---|
| 畫風跑掉 | 「畫風跟附圖差太多，請完全照附圖的線條、上色方式和頭身比例重畫」 |
| 長得像真人 | 「請改得更 Q 版、更卡通，不要像真人」 |
| 圖上出現文字 | 「請移除畫面上所有文字和符號」 |
| 背景不透明 | 「請把背景改成透明」（不行就用 Finder 的移除背景） |
| 角色太小或被裁掉 | 「角色要完整全身入鏡，上下左右留一點空白」 |
| 表情不夠誇張 | 「表情再誇張兩倍，像搞笑漫畫那樣」 |
| 被拒絕生成 | 把「整人」「加料」換成「惡作劇」，強調是 Q 版搞笑喜劇 |
