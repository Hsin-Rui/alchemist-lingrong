# 煉金術士零溶——第二輪：調合更好玩、拜訪交朋友、教學與可分享的結局

## Description

v1 已上線可玩。第二輪依使用者 2026-11-23～24 的四個目標改版：調合從點來點去變成有配方冊和四階段小遊戲；「送禮」改成拜訪各宮、各人有藏起來的喜好；開場和教學由包捐帶著玩；結局拆成兩個畫面並能分享成圖卡。配方、素材與料也換成原作梗。玩法與數值一律以 `docs/game-design.md` §7–9、§13–15 為準，台詞以 `docs/round2/lines-review.html` 為準。

## Outcome

玩家在手機或電腦上玩一輪時，調合和交朋友都有取捨與驚喜，新手由包捐帶著上手，玩完能把封號圖卡分享給朋友。

## Requirements

- R1 (§8, §7 取得): 新配方 7 道＋紅花；12 種正經素材以「一份一份」記錄；除紅花瓣外所有東西小舖都買得到；採集的素材依本性隨機帶 0–2 個特性（離出生點越遠等級越高），小舖的沒有；多的素材可在小舖賣（售價一半＋每級特性 1 兩）。
- R2 (§13.3–13.5): 調合分四階段——選素材（配方冊標示可做／缺什麼、選用哪一份、可自由調合、支援三素材配方）→ 開火攪拌（三選一冒泡 3 次）→ 加料 → 起鍋（珠珠升／不變／降）；快速調合跳過二、四；配錯做出黑暗料理；有演出；電腦鍵盤與手機都能玩。
- R3 (§13.1–13.2): 五種特性（香氣、甜蜜、華麗、清雅、濃郁）各 1–3 級，成品最多 3 種，從素材與攪拌而來。
- R4 (§14.1–14.3): 拜訪各宮取代送禮——花 1 時辰、次數不限，空手友好 +1 或帶伴手禮；友好＝(基本值＋喜歡特性每級 +1－討厭特性每級 −1)×成品係數 1.2／1／0.8；喜好藏起來、不暗示、不記錄；反應依喜歡與討厭抵銷決定投其所好／嫌棄／又愛又嫌／普通；收禮機率＝友好＋30%，嫌棄再 −20%。
- R5 (§14.4): 訂單由宮女（吹緊吸、踩月、送吱）來下；交貨可親自（賞銀＋友好 5＋每 3 級特性總和 +1）或包捐代交（只有賞銀）；滑妃會不時點坐胎藥。
- R6 (§14.5, §7): 加料的禮誰都能收；料為麝香、紅花、木薯粉（上吐下瀉）、貓薄荷（貓咪鬧場）；被抓機率先以遮掩分（濃郁×2＋香氣＋甜蜜）壓低、最低 8%，再乘友好與交貨倍率；基礎機率 12／45／18%。
- R7 (§15.5): 禁足時才能抄經（1 時辰、從 6 句台詞挑一句排字），得到《後宮心經》，送誰都友好 +5、不拒收；禁足時包捐提示可代交、可抄經或調合。
- R8 (§15.1–15.4): 新開場對話並詢問是否進教學；教學模式第一天固定真環的藕粉桂花糖糕訂單、開局沒有桂花，引導採集→調合→親自交貨→夜晚；第一次加料／被翻牌子／禁足時包捐說明（不分模式）；包捐每天一句提醒。
- R9 (§9 第二輪): 結局拆成兩個畫面——恩寵榜從第 4 名揭曉到第 1 名；封號蓋章＋kuso 戰績；新增封號原著重現、炎洗宮米其林、甘露寺預備役、包捐才是本體（共 16 個）。
- R10 (§9 分享): 分享 prototype——瀏覽器畫出 1200×630 圖卡；手機用系統分享、電腦存圖；「分享到 FB」按鈕分享遊戲網址。
- R11 (lines-review): 遊戲台詞依台詞總表定稿；稱呼一律安小主（妃嬪當面叫安妹妹），零溶自稱我。
- R12 (§14 開頭, §12.9): 模擬器跟著新規則更新，量出各機器人的逆襲率與封號取得率，用來調數值與封號順位。

## Constraints

- 純前端靜態網站、無後端；分享後台留到下一個 iteration（自己的 VM）(§9 分享, §16)。
- 電腦鍵盤與手機觸控都要能玩 (§13.3)。
- 規則放在 DOM-free 引擎並有單元測試（沿用 v1 R6 的架構）。
- 遊戲畫面不出現英文；零溶自稱我；不出現「安嬪」(§9, §14.6)。

## Done when

- 一輪 10 天能用新配方、四階段調合、拜訪、新料從開局玩到結局，無卡死與 console 錯誤（自動 harness ＋ 使用者試玩）。
- 引擎單元測試涵蓋素材份與特性、調合、送禮友好與反應、被抓機率、抄經，全部通過。
- 模擬器以新規則跑完，逆襲率與 16 個封號的取得率寫回 §9，封號順位據此調整。
- 選「好，妳說吧」的新玩家能只靠包捐引導完成第一天的採集→調合→交貨。
- 結局兩個畫面與分享圖卡在手機與電腦都能用，已部署到 GitHub Pages。

## Boundaries

- 不做：特性組合技、搞笑特性、零溶自用品、歡宜香、分享後台（下一個 iteration）。
- 採集地下城的玩法不變，只換素材表與加上特性 (§12)。
- Touch point: 採集地下城的素材表 — 換成新素材與特性；owner: epic-materials-recipes
- Touch point: tools/simulate.js、tools/gather-bot.js — 跟著新規則更新；owner: epic-visit-palaces
- Tracer path: 素材份＋新配方（地基）→ 四階段調合產出帶特性的成品 → 拜訪送禮用到特性與喜好 → 禁足抄經 → 開場教學串起來 → 結局與分享收尾。
