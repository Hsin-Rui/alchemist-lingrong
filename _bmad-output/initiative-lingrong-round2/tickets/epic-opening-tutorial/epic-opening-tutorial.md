# 開場與包捐教學

## Description

照 §15.1–15.4 換掉開場對話，加入可選的教學模式帶完第一天，第一次加料／被翻牌子／禁足時包捐說明，包捐每天一句提醒。

## Outcome

新玩家能被包捐帶著上手，老玩家可以跳過。

## Done when

- 開場對話與教學選項照 §15.1。
- 教學模式第一天能只靠引導完成採集→調合→親自交貨→夜晚。
- 第一次碰到時的說明與每天一句照台詞總表。
- 已部署，使用者試玩過。

## Boundaries

- 不教喜好、不提醒加料白費（使用者決定）。
