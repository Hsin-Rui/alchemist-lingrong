# 煉金術士零溶 — 操作與手感規格（epic-ux-input）

## Foundation

手機直式優先的網頁遊戲，桌機以同一個直式欄置中遊玩。沒有 UI 框架；既有畫面由 `js/game.js` 以 HTML 字串繪製、在 `#app` 上用 `data-a` 委派點擊。外觀見 `DESIGN.md`，本文件定義行為。

本版目標：桌機玩家能**只用鍵盤**流暢玩完一輪；對話可以加快；加料、害人、被抓的演出更有份量。手機觸控操作不得退步。範圍外：遊戲規則與數值、採集地下城的玩法（其鍵盤操作維持現狀）。

## Information Architecture

畫面不增不減，只說明每個畫面的鍵盤落點。「預設」＝進入畫面時游標停的位置，也是游標未出現時按 Enter 會按下的那一顆。

| 畫面／視窗 | 進入方式 | 預設 |
|---|---|---|
| 標題 | 開啟遊戲 | 開始遊戲 |
| 對話（疊在畫面上） | 各種事件 | —（空白／Enter 推進） |
| 主畫面 | 對話結束、各處返回 | 最上面一張訂單卡的主要按鈕；沒有訂單時為導覽列「採集」 |
| 小舖 | 1 | 第一個買得起的商品 |
| 採集（選地點） | 2 | 第一個可去的地點按鈕 |
| 採集地下城 | 選地點 | 沿用現有按鍵，無游標 |
| 採集結果 | 地下城結束 | 「直接去調合」；沒有則「回炎洗宮」（不預設「再去採一次」） |
| 調合 | 3、訂單卡 | 第一個可用素材 |
| 調合完成 | 調合結束 | 「直接送去」；沒有則「回炎洗宮」 |
| 送禮 | 4、侍寢卡 | 目前選定對象的第一個「送出」 |
| 後宮榜 | 5 | 返回 |
| 交貨／送禮結果 | 對話結束 | 回炎洗宮 |
| 就寢確認 | 6、導覽列 | 確定就寢 |
| 金縷衣（鎖定） | 侍寢夜 | 唱金縷衣（使用者指定：預設唱） |
| 夜晚總結 | 夜晚對話結束 | 就寢，迎接明天 |
| 結局 | 第 10 天後 | 再玩一次 |

原則：**會花時辰的按鈕不當預設**；真正花時辰的動作，要玩家自己移過去再按。

## Voice and Tone

| 改 | 為 |
|---|---|
| 對話右上「快轉 ≫」 | 「略過 ≫」 |
| （新）倍速按鈕 | 「▶ 2×」／「▶ 瞬間」 |

其他文案不動。

## Component Patterns

| 元件 | 行為 |
|---|---|
| 游標（焦點框） | 方向鍵照**畫面方位**移動：往按的方向找最近的可按元素。到邊緣不繞回。停用的按鈕跳過。重繪畫面後游標留在同一個動作上（同一顆按鈕仍在時）。 |
| 游標顯示 | 只在按過方向鍵後出現；之後一用滑鼠或觸控就隱藏。手機永遠看不到。 |
| Enter | 按下目前游標所在元素；游標未出現時按下該畫面預設。 |
| 對話 | 空白／Enter：文字跑到一半時補完整句，已完整則換下一句。連按即可一路往下。點畫面同效果。 |
| 對話速度 | 兩段：**2×**（預設，約每秒 70 字）、**瞬間**（每句直接整句出現）。Shift 單獨按放切換（與其他鍵組合時不算），或點倍速按鈕。不記住，每次開遊戲回到 2×。 |
| 略過 | Esc 或點「略過 ≫」：跳過整段對話。不受防連按影響。 |
| 防連按 | 只擋三個時刻：**被抓的那一句**、**加料得手的那一句**、**早上「今晚黃上翻的是您的牌子！」**。這些句子直接整句顯示，0.6 秒內按鍵無效，▼ 0.6 秒後才出現。開場教學不擋。 |
| 數字 1～6 | 1 小舖、2 採集、3 調合、4 送禮、5 後宮、6 就寢。主畫面與子畫面都有效；對話中、彈出視窗開著時、調合進行中、採集地下城中無效。6 走現有的就寢確認。 |
| Esc（非對話） | 返回上一層；彈出視窗開著時關閉視窗。鎖定視窗（金縷衣）按 Esc 無效。採集地下城中＝收工（沿用）。 |
| M | 開關聲音。 |
| Tab | 保留瀏覽器預設，不另做用途。 |

## State Patterns

| 狀態 | 處理 |
|---|---|
| 游標隱藏（預設、滑鼠、觸控） | 不畫焦點框；Enter 仍按下預設。 |
| 游標顯示 | 四角框圍住目前元素（`DESIGN.md` 焦點框）。 |
| 對話被擋中 | ▼ 隱藏，按鍵無效 0.6 秒。 |
| 彈出視窗開著 | 游標只在視窗內移動；數字鍵無效。 |
| 鎖定視窗 | 同上，且 Esc 無效。 |
| 調合進行中 | 數字鍵無效。 |
| 減少動態效果（系統設定） | 不搖晃；其他演出照常。 |

## Interaction Primitives — 演出

事件分輕重，演出依等級組合。**對話中一律不搖晃**；搖晃只在「重」事件的結果頁蓋章時出現一次。

| 事件 | 等級 | 章 | 對話中 | 結果頁蓋章時 |
|---|---|---|---|---|
| 狂癢、口臭、腹瀉 | 輕 | 紅 | 受害者立繪跳起來抖；零溶奸笑時立繪慢慢放大特寫 | 狠章＋停格約 0.07 秒；受害者立繪被震得往下一縮 |
| 麝香累積（n/3）、麝香落空 | 中 | 紫 | 零溶奸笑特寫 | 狠章＋停格約 0.12 秒；立繪輕跳 |
| 不孕、小產 | 重 | 紅 | 旁白重擊句：文字框「砰」地彈一下；受害者抖、零溶特寫 | 狠章＋停格約 0.19 秒＋**畫面搖晃一次**；受害者被震 |
| 被抓 | 重 | 紅 | 溫太醫從右側衝進來；受害者抖；零溶嚇得往後退；宣判句起**畫面變暗**（0.9 秒暗到 45%） | 狠章＋停格約 0.19 秒＋搖晃一次；章落下後再暗到 62%；章、收據、按鈕不被壓暗 |
| 收下、拒收、無效 | — | 金／灰 | 照舊 | 照舊（一般章，不搖晃） |

搖晃分級（只有「重」用到）：振幅 15px、約 0.76 秒，逐漸衰減停下。等級與時間的參考實作：[mockups/fx-demo.html](mockups/fx-demo.html)。規格表為準；示範頁內的「輕／中搖晃」選項已不採用。

麝香 n/3 與麝香落空同屬「中」；小產與不孕同屬「重」。

## Accessibility Floor

- 所有遊戲動作都能只用鍵盤完成；採集地下城沿用既有鍵盤。
- 焦點框清楚可見（淺色面朱紅、深色面琥珀），且不靠改變按鈕本身來表示焦點。
- 系統開啟「減少動態效果」時不搖晃。
- 不做閃色。
- 觸控操作與現狀一致：按鈕尺寸、點擊推進對話、略過按鈕都不變；新增的倍速按鈕與略過同尺寸（至少 40px 高）。

## Responsive & Platform

- 桌機（有鍵盤）：本文件全部行為。
- 手機（觸控）：游標永遠不出現；能點的東西照舊，新增「倍速」按鈕。演出與桌機相同，搖晃照「減少動態效果」設定。
- 外接鍵盤的平板：與桌機相同。

## Key Flows

### Flow 1 — 純鍵盤玩一輪（小芸，上班族，晚上下班後在沙發用筆電，不想碰觸控板）

1. 標題頁按 Enter，開始遊戲（游標還沒出現，Enter 按下預設）。
2. 開場教學連按空白鍵；嫌慢，按 Shift 切成「瞬間」。
3. 第 1 天早上，寶娟：「今晚黃上翻的是您的牌子！」——這句擋 0.6 秒，她看清楚了。
4. 主畫面按 ↓，四角框出現在最上面一張訂單卡的主要按鈕；方向鍵在侍寢卡、訂單卡、導覽列之間照方位移動。
5. 按 2 開採集，↓ 選御花園，Enter 進入地下城；照現有按鍵玩完，結果頁游標停在「直接去調合」。
6. 調合：游標停在第一個素材，Enter 放入，再往下選料，到「開始調合」按 Enter；完成後游標停在「直接送去」。
7. 送貨：滑妃「本宮先失陪一下——！」立繪跳起來抖，零溶奸笑特寫；結果頁紅章「腹瀉」狠狠砸下、停格、噴墨，不晃。Enter 回宮。
8. 按 6 就寢，確認視窗 Enter；金縷衣視窗 Esc 沒用，她用 ← → 選好按 Enter。夜晚對話連按空白，夜晚總結 Enter 迎接明天。
9. **高潮（第 7 天）**：溫太醫衝進來「且慢！」——擋 0.6 秒；宣判時畫面慢慢暗下，「被抓」紅章重重砸下、停格、畫面晃一次，暗幕再沉一點。小芸倒抽一口氣，Enter 回宮。
10. 結局：方向鍵在封號印章之間移動，Enter 看說明，最後到「再玩一次」。

失敗情況：她用了一下觸控板點按鈕 → 焦點框隱藏；再按方向鍵 → 焦點框從目前畫面的預設重新出現（從預設，而非上次位置）。

### Flow 2 — 手機直式（不退步）

1. 同一位玩家改用手機玩：所有畫面照舊點擊操作，看不到焦點框。
2. 對話多了「▶ 2×」按鈕，點一下變「瞬間」；「略過 ≫」照舊。
3. 加料、被抓的演出與桌機相同；手機開了「減少動態效果」就不晃。
